# SIPlah Toko Ladang Cabang Bandar Lampung
Sistem Inventory & Komisi Sales Toko Ladang
(Manajemen Stok Barang + Perhitungan Komisi Sales Berbasis Web)

🔧 Teknologi yang Digunakan
✅ Backend:

PHP (CodeIgniter 3)

MySQL
✅ Frontend:

Bootstrap 5 + AdminLTE (Dashboard)

DataTables (Tabel Interaktif)

jQuery & AJAX
✅ Fitur Khusus:

Perhitungan Komisi Sales Otomatis (%)

Laporan Penjualan (Harian/Bulanan)

🎯 Fitur Utama
1. Manajemen Inventory
Tambah/Edit/Hapus Barang

Kategori Produk (Pupuk, Alat Pertanian, dll)

Stok Opname & Notifikasi Stok Habis

2. Manajemen Sales & Komisi
Master Data Sales (Nama, No. HP, Persentase Komisi)

Perhitungan Komisi Otomatis (X% dari Total Penjualan)

Riwayat Komisi (Filter Berdasarkan Periode)

3. Transaksi & Laporan
Input Penjualan (Kasir)

Cetak Invoice (PDF)

Dashboard Analisis:

Grafik Penjualan per Sales

Laba Rugi
